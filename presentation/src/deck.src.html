Honest scope

Telemetry is simulated by a physics model, not a live NCPOR feed. The ingestion layer is built and typed, so a real feed replaces the simulator, not the system.

Antarctic Digital Twin05 / 08

Ordinary web technology, aimed at an extraordinary environment

No exotic hardware and no new sensors. NCPOR already collects this data; the gap is that it is scattered.

Feasibility & Viability
Why it is viable

The whole system runs on a standard laptop or an existing station server, and the entire stack is open source. There is no procurement step and no licence cost between a decision to trial it and a station running it.

0
new sensors required
2
commands from clone to running console
Limited satellite bandwidth

Server renders the HTML. The browser polls a small JSON payload and patches numbers in place instead of reloading.

Connectivity blackouts

The station side buffers readings and forwards them when the link returns. The console shows last-known state with an explicit timestamp.

Sensor failure or bad data

Range checks per field at ingestion. Readings outside physical bounds are rejected and flagged, never silently averaged in.

Access & authorisation

Phased rollout. Non-sensitive operational telemetry first, role-based access before any control capability is considered.

Impact & Benefits
Measured on the live prototype
−57.4 °C
Wind chill at Maitri, surfaced as a critical while there is still time to suspend a traverse.
15 days
Gap between rations endurance and the resupply window, flagged months before the shortfall.
4 sources
Diesel, solar, wind and battery tracked together, so refuelling follows a trend rather than a low-level alarm.
Who benefits

Station crew. Hazards escalate before they become emergencies, in months when no help can arrive.

NCPOR operations, Goa. One authoritative picture of both stations, not reconciled reports.

MoES planners. Resupply and fuel decisions backed by trends, not the last message received.

Wider value

Economic. A missed resupply window costs a full season.

Environmental. Renewable share stays visible, so diesel use can fall.

Scalable. Station profile is data, not code. Himalayan posts or offshore platforms are a config entry.
